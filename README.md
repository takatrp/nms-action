# NMS ACTION

目標・候補案件・具体施策・入会後フォローをつなぐ、日本語の活動支援Webアプリです。PC・スマートフォンから利用できます。

## 使い方

1. 「目標・設定」で対象範囲、基準日、基準事務所数、目標、期日、新規入会人数を設定します。全国・地域会・支部の目標はそれぞれ独立です。
2. 候補案件を匿名コードで登録し、主担当・課題・次の行動・期限・連絡制約を記録します。
3. 「施策・実行」で推薦理由を確認し、12の施策から採用します。3〜5タスクが生成され、担当・期限・指標を編集できます。
4. 「抵抗・対策」で必要な仮説一つを本人に確認します。確認済みの回答は質問・再確認タスクへ反映されます。
5. 実績を確認してから、案件段階・入会後3回の支援・確定入退会台帳をそれぞれ記録します。タスクチェックは自動的に実績へ変換されません。
6. 振り返りに改善行動を残し、定期的にJSONバックアップを保存します。

## 計算と運用の約束

- 事務所純増と新規入会人数は別々に集計。候補案件は実績に含めません。
- 集計は基準日の翌日から今日または目標期日の早い日まで。範囲に属する実績は下位を含め1回ずつ集計し、子の基準数を親に加算しません。
- K段階は現在在籍数。倍率は入会1人に必要な各状態の未入会人数の設定目安で、段階間の乗算・到達累計・成約確率には使いません。
- 見学後7日は実参加日+7暦日。参加予定・欠席の日付を実参加欄に入れません。採用日から締切を延長しません。
- 施策の質問、手順、7日以外の日数は編集できるアプリ提案です。実在のイベント・サービス・費用・支援範囲を個別に確認します。
- 本人の辞退・連絡停止・保留期限を優先します。退会や見送りを妨げません。
- 3回の支援や在籍3年は自動的な解決・支援終了・削除の条件ではありません。
- 抵抗は未確認から開始し、属性・無返信・日数から自動判断しません。実際の費用、時間、不適合を心理的問題に置き換えません。

## 保存とプライバシー

初期データは空です。元PDF、内部資料、非公開数値、名簿、会員・顧客データは含みません。
入力内容はブラウザのlocalStorageへ保存し、アプリから外部へ送信しません。解析、外部AI、外部フォント、同期サーバーは使用しません。
GitHub Pagesへのアクセス自体はGitHubの通常のアクセス処理対象です。共同編集・自動共有機能はありません。

ブラウザのデータ削除、シークレットモード、端末変更では保存データを失う場合があります。JSONで退避してください。JSONには入力した情報が含まれます。
ブラウザ保存は暗号化された業務データベースではありません。端末のアクセス管理を行い、匿名コードでの運用を推奨します。
破損JSONは拒否し、復元は件数プレビューと確認後に全体置換します。別タブの変更があれば保存を拒否し、再読み込みを案内します。
通常のJSONバックアップの出力・読込みは、UTF-8で5MB（5,000,000バイト）以下です。バックアップが上限を超える変更は保存せず、現在のデータを維持します。
ダウンロード開始の通知後、保存先にJSONファイルがあることを確認してください。既存データが上限を超える場合、通常の出力は中止して理由を表示します。破損元データの退避は復旧用のため、この通常バックアップ制限の対象外です。

## 抵抗理論の出典

Loran Nordgren / David Schonthal『The Human Element』の四つの摩擦（Inertia, Effort, Emotion, Reactance）を参考にしています。
邦訳の表記は「惰性・労力・感情・心理的反発」です。
段階別の仮説、質問、施策との対応は本アプリ向けの応用提案で、著者・TKCが検証や認定をした診断モデルではありません。

- [著者公式](https://www.humanelementbook.com/)
- [草思社の邦訳紹介](https://www.soshisha.com/book_search/detail/1_2624.html)

## 開発・確認

Node.js 22以降。外部パッケージ依存なし。

```sh
npm test
npm run check
npm run build
npm start
```

http://127.0.0.1:4173 を開きます。ビルドは公開する7ファイルと`.nojekyll`のみを明示コピーします。
テストは単位・階層集計・日付・推薦抑制・施策重複・抵抗根拠・JSON形式・入力エスケープを確認します。

GitHub Pagesは`main`の`/docs`を公開します。公開前に38テスト・構文・静的ビルドを確認し、生成物を`docs/`へコピーします。Pages標準ワークフローで配信を確認します。

## 確認状況

JSON生成・復元・5,000,000バイト上限・保存データ保護の論理は自動テスト済みです。ブラウザのJSONダウンロード通知は10秒でタイムアウトし、実ファイル保存は未確認です。ダウンロード一覧ページは操作ポリシーで拒否されたため確認していません。バックアップ時は保存先の実ファイルを確認してください。
